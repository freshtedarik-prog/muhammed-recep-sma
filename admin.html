İlk Kurulum

Bu cihazda paneli ilk kez açıyorsunuz. GitHub anahtarını bir kez girip kendinize bir PIN belirleyin. Sonraki girişlerde sadece PIN yeterli olacak.

GitHub anahtarı nasıl alınır?
  1. github.com'a freshtedarik-prog hesabıyla giriş yapın.
  2. Sağ üstte profil resmi → Settings → en altta Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Token name: Site paneli. Expiration: en uzun süreyi seçin.
  5. Repository access: Only select repositories → muhammed-recep-sma.
  6. Permissions → Repository permissions → Contents: Read and write.
  7. Generate token'a basın, github_pat_ ile başlayan anahtarı kopyalayıp aşağıya yapıştırın.

Bu anahtar yalnızca bu sitenin dosyalarını değiştirebilir. Kimseyle paylaşmayın.
